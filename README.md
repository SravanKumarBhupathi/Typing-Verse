# TYPEVERSE — Type. Compete. Level Up.

**TYPEVERSE** is a production-grade typing education, esports, and multiplayer arcade gaming ecosystem where real typing speed (Net WPM), keystroke accuracy, consistency, and combo streaks directly power gameplay.

## Core Platform Capabilities

1. **Complete 6-Stage Typing Academy (21 Structured Lessons)**:
   - Stage 1: Beginner Fundamentals (Home row anchors F & J, keyboard anatomy, sitting posture).
   - Stage 2: Foundation Rows (Top row, Bottom row, full alphabet).
   - Stage 3: Word Mastery (Digraphs, alternating hands, double letters, zero-backspace accuracy).
   - Stage 4: Sentence Mastery (Opposite-pinky Shift coordination, punctuation, multi-clause prose).
   - Stage 5: Advanced & Technical (Number row, developer syntax & brackets, scientific vocabulary).
   - Stage 6: Expert & Esports Mastery (65+ WPM velocity sprints, 98% surgical precision challenges).
2. **Central Zero-Lag Typing Engine**:
   - Supports 15s, 30s, 60s, 2m, 3m, and 5m durations across 10 categories (Easy, Medium, Hard, Expert, Quotes, General English, Technical, Numbers, Symbols, Custom Text).
   - Transparently calculates Gross WPM, Net WPM, Accuracy, CPM, Consistency, Reaction Time, and Keystroke Error distributions.
3. **Six Distinct Skill-Driven Arcade Games**:
   - **Meteor Defender** (Space Arcade Survival with Boss Meteors)
   - **Type Racer GT** (4-Lane Circuit Racing)
   - **Spell Caster** (Arcane Fantasy Combat with Critical Multipliers)
   - **Word Defender** (3-Lane Tactical Tower Defense)
   - **Cyber Duel** (1v1 Synchronized Combat Arena)
   - **Word Survival** (Volatile Countdown Fuse Endurance)
4. **Simulated Bot Battle System (5 Tiers)**:
   - Easy (15–25 WPM), Medium (30–45 WPM), Hard (50–65 WPM), Expert (70–90 WPM), and Adaptive (103% of user average WPM), complete with realistic inter-keystroke jitter, occasional typos, and backspace corrections.
5. **Real-Time Friend Multiplayer (`server.ts` WebSockets + Optional Supabase Realtime)**:
   - Instant 6-character room codes, custom room codes, host settings, ready status, synchronized 3-2-1 countdowns, live opponent progress bars, disconnect/reconnection handling, and rematches.
6. **Ghost Racing, Shareable Challenges, Tournaments, Adaptive Learning & Verified Certificates**:
   - Checkpoint-based Ghost Racing against Personal Best runs.
   - Shareable URL challenges (`?challenge=ID`) across 5 modes.
   - Private & Public Tournament brackets (`single-elimination`, `knockout`, `round-robin`, `best-of-three`).
   - 10 Career Ranks (Rookie to Typing Legend) + 12 Achievements + Daily/Weekly Quests + PWA offline compliance.
